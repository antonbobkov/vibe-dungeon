# UNDERVAULT — 04: UI, HUD, Screens, Font, Audio

Presentation-layer spec. Nothing here affects the simulation. All colours are Pack A
palette colours (AG §2.4) plus `#ffffff` (already used by damage flashes). All pixel art
in this file is embedded as bitmaps below — no external assets.

## 1. HUD (top 16 px strip, always visible during play)

Background `#25131a`; a 1 px separator line `#3d253b` along y=15. Contents, left to right
(all y-positions within the strip):

| Element | Position | Rendering |
|---|---|---|
| Hearts ×3 | x = 4, 14, 24; y = 5 | 7×6 bitmaps (§2). HP 6..0, 2 HP per heart: full / half / empty |
| Silver key icon + count | icon x=40 y=0 (16×16 sprite `(8,8)`); count in font at x=57 y=6 | hidden when count is 0 |
| Gold key icon | x=72 y=0, sprite `(9,9)` | shown only while held |
| Coin icon + treasure count | icon x=96 y=0 sprite `(6,8)`; count at x=113 y=6 | always shown, up to 2 digits |
| Floor label | right-aligned, x=316 y=6 | `F1`..`F4`, colour `#ffd569` |

Font text in the HUD is `#adc1cf` unless stated.

## 3. Screens

### 3.1 Title

Background `#25131a`. Elements (logical px, screen is 320×208):

- `UNDERVAULT` — font ×3, `#ffd569`, centred, y=48.
- Player knight sprite (idle anim) ×2 scale, centred, y=92.
- Two lit wall-torch anims (`torch/torch_*`) at x=124 and x=180, y=92 (1× scale).
- `PRESS X TO BEGIN` — font ×1, `#adc1cf`, centred, y=150, blinking 30 ticks on / 30 off.
- `ARROWS OR WASD TO MOVE   X SWING   Z USE` — font ×1, `#90919e`, centred, y=172.

ATTACK starts floor 1 (fade to black 30 ticks, then floor 1 fade-in).

### 3.2 Death

Part of the death sequence (01 §6): during the 30 ticks of black before respawn, show
`YOU FELL` — font ×2, `#bc4c51`, centred. No input required; respawn is automatic.

### 3.3 Victory

Triggered by the `victory` wiring effect (Great Vault chest). Sequence: sim stops; hold
60 ticks on the open chest; fade to `#25131a` over 60 ticks; show:

- `THE VAULT IS YOURS` — font ×2, `#ffd569`, centred, y=56.
- Knight sprite ×2 centred y=84, gold-key sprite spinning (`keys/keys_1_*`) beside it.
- Stats, font ×1 `#adc1cf`, centred, line spacing 12 px starting y=116:
  `TIME MM:SS` (play ticks ÷ 60 → seconds, zero-padded) · `DEATHS N` · `TREASURE n/83`.
- `THANKS FOR PLAYING` — font ×1, `#90919e`, centred, y=168.

ATTACK returns to the title screen (full state reset).

### 3.4 Pause

Overlay on the frozen game frame: every other pixel row darkened to 40% (scanline dim —
deterministic, no alpha blending needed on palette art), `PAUSED` font ×2 `#ffd569`
centred. Escape/P resumes.

## 5. Audio (WebAudio synth — no audio assets exist; all cues generated)

One master gain at 0.2; `M` toggles mute (persisted in localStorage; not sim state).
Envelope: linear attack 5 ms, linear release over the stated duration unless noted.
"sweep" = linear frequency ramp over the duration. "arp" = equal-length note sequence.

| Cue | Trigger | Synth |
|---|---|---|
| sword | swing starts | square 180→90 Hz sweep, 70 ms |
| hit | swing connects | square 110 Hz 60 ms + white-noise burst 40 ms |
| hurt | player damaged | sawtooth 140→70 Hz, 150 ms |
| coin | coin collected | square 880 Hz 40 ms then 1320 Hz 60 ms |
| key | key collected | triangle arp 660/880/1100 Hz, 150 ms total |
| flask | flask collected | triangle 520→780 Hz, 120 ms |
| door | door opens/unlocks | square 220 Hz 100 ms then 110 Hz 100 ms |
| locked | locked door bumped without key | square 98 Hz, 80 ms |
| chest | chest opens | triangle arp 523/659/784 Hz, 200 ms total |
| crate | crate destroyed / crate lands in pit | white noise, 80 ms |
| push | crate slide starts | triangle 90 Hz, 100 ms |
| torch | puzzle torch lit | triangle 700 Hz, 60 ms |
| seal | combat seal closes | square 98 Hz, 200 ms |
| wave | wave telegraph starts | triangle 440 Hz, 80 ms |
| enemy_die | enemy death | square 260→65 Hz sweep, 180 ms |
| death | player death | sawtooth 220→55 Hz, 500 ms |
| descend | ladder used | triangle 330→165 Hz, 300 ms |
| victory | victory screen | square arp 523/659/784/1046 Hz, 500 ms total |

Audio is milestone M7 (optional-but-specified); the game must be fully playable silent.
